## 5. 请求导出为 Anki 文件

**输入**：

这个 Skill 不生成 Anki 文件。以下提供其支持的 Markdown 知识卡片；原文只有一个独立知识点，因此输出 1 张。

### 卡片 1：备份同时保留原文件与副本

- **核心知识**：备份是保留原文件，同时在另一个位置保存副本。

- **自测问题**：备份是否需要保留原文件，副本保存在哪里？参考答案：需要保留原文件，副本保存在另一个位置。
